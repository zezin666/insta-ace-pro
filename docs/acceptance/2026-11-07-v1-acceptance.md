## 关键修复（验收过程中发现）

1. **相机 HTTP 连接复用错位**：相机内置 HTTP 服务在连接复用时会把文件体当状态行返回（`Unexpected status line: ... ExifII*`），导致照片/下载随机失败。已禁用连接池复用并允许连接失败重试，照片与下载随即稳定。
2. **WiFi 重连超出重试窗口**：设备 WiFi 重连约需 15–30 秒，原来 3 次（1s/2s）重试会在重连前耗尽。改为最多 7 次尝试（1/2/4/8/16/32s，约 63 秒），自动续传通过。
3. **诊断日志**：下载失败时写入 `AceDownload` 日志，错误详情也显示在下载面板。

## 已知限制（v1）

- 已下载标记只识别本 App 下载的文件；官方 App 或 USB 导入的同名文件不会被标记。
- 不做 VPN 分流。若官方 App 的分流 VPN 处于开启状态，可能影响相机网络绑定。
- 不做删除、拍摄控制、云服务、360 拼接和编辑。
- 缩略图协议为相机私有 NV12 格式，固件升级后若格式变化，走 HTTP/EXIF 回退。
- 本次验收在 Redmi K40 / MIUI 上完成；用户确认以此设备结果为准。一加 Ace 3 Pro / ColorOS 16 尚未实测。
- 双指缩放与双击复位已由用户手动确认通过。
